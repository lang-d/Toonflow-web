# 3D 导演台前端需求说明

## 定位

3D 导演台是图片编辑画布内部的可编辑引用节点，用来辅助生成分镜图、场景图和构图参考图。它不是生产台主流程节点，不参与生产台主画布的脚本、资产、分镜、视频工作台固定链路。

## 前端负责

- 在图片编辑画布中提供 `directorStage` 节点。
- 支持从已有上传节点、生成图节点和导演台资产节点接收引用素材。
- 提供全屏导演台编辑器：场景层级、导演视图/机位视图、角色站位、姿势、机位和截图管理。
- 将“场景图、站位图、机位截图、构图参考图”提交给后端保存为导演台资产。
- 后端返回 `MediaRef` 后，把导演台资产作为 `ReferenceImage(source: "directorAsset")` 输出给下游生图节点。
- 画布保存时只保存导演台草稿、已入库资产引用和连线关系，不保存长期 base64。

## 前端不负责

- 不把导演台作为生产台主流程节点。
- 不直接设计数据库表或资产库结构。
- 不直接写磁盘路径。
- 不绕过后端调用云端供应商。
- 不把临时截图 URL 伪装成资产。
