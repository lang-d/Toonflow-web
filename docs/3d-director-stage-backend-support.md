# 3D 导演台后端支撑需求

本文只描述前端需要的后端能力，不规定数据库结构。当前导演台定位为图片编辑画布内部节点。

## 1. 导演台资产

导演台产物需要作为新资产进入统一资产体系：

- 场景图
- 站位图
- 机位截图
- 构图参考图

前端通过 `POST /production/editImage/createDirectorAsset` 提交截图和上下文，后端返回资产 ID 与 `MediaRef`。详细请求响应见 `docs/director-stage-asset-backend-contract.md`。

## 2. 资产复用

后端需要让导演台资产可以被以下场景复用：

- 图片编辑画布生成节点引用。
- 其他图片编辑画布引用。
- 分镜台引用。
- 视频生成台引用。
- 资产选择器检索和展示。

生成链路继续使用 `media.path` 作为原图事实来源。

## 3. 后续导演场景持久化

正式版本建议后端支持导演场景保存/读取：

- 背景场景引用。
- 角色、道具引用。
- 角色和道具的站位、缩放、旋转、姿势。
- 多个机位和机位截图。
- 与当前画布、分镜或目标资产的关联关系。

第一版前端会把导演台草稿保存在图片编辑画布节点数据里，等后端正式契约稳定后再迁移。

## 4. 供应商能力

多角度场景生成、可移动场景重建、动作捕捉等高算力能力仍归供应商配置管理。前端不会直接连接云端应用，只调用后端提供的供应商任务接口和统一 TaskCenter 任务状态。
